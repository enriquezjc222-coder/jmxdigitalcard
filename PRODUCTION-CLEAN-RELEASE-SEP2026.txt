GitHub conflict prevention
--------------------------
The previous publishing problem happened because an older local Git repository was behind origin/main and had a separate local production commit. Git then tried to rebase two histories that modified the same dashboard/backend files.

This ZIP intentionally contains NO .git directory.
A helper script is included:
  PREPARE-GITHUB-CLEAN.ps1

It clones the CURRENT GitHub main branch into a new temporary folder, configures the repository-local author as enriquezjc222-coder, overlays this approved production build, and shows git status. It does NOT commit and does NOT push.
