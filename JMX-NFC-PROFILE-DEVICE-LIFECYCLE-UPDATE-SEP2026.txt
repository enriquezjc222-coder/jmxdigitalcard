WHAT WAS ADDED
1. CREATE NEW PROFILE directly inside Official JMX NFC Clients.
   - Customer Name, Company, Email, Phone, Plan, Admin Notes.
   - Generates a permanent internal Profile ID (PROF-...) and Card ID.
   - Stores creationMethod=official-device-id-profile.
   - Keeps legacy/public profile URL for compatibility, but Official JMX NFC devices continue to use /d/DEVICE-ID.

2. CLIENT NFC QUICK ACTIONS
   - Add NFC Devices (opens Create Batch already assigned to the selected profile).
   - Assign Existing Batch (select an unassigned/existing batch and assign it without regenerating Device IDs).
   - Suspend / Reactivate / Archive Profile.

3. CLIENT NFC MASTER SWITCH
   - All Official NFC Devices ON/OFF per client using cards.nfcDevicesEnabled.
   - Existing per-device-type client controls remain.
   - Backend resolver now enforces the client master switch.

4. DEVICE LIFECYCLE
   - Active / Pending / Available
   - Suspended
   - Lost
   - Stolen
   - Replaced
   - Retired
   - Archived
   - Lost/Stolen/Retired/Archived are disabled and are not automatically reactivated by Batch OFF->ON.

5. DEVICE ACTIONS
   - Copy NFC URL
   - Suspend / Reactivate
   - Mark Lost
   - Mark Stolen
   - Replace Device
   - Retire
   - Archive
   - Open Batch

6. BATCH SAFETY
   - Batch disable/reactivate preserves terminal individual device states.
   - Assign/Transfer Batch preserves Lost/Stolen/Replaced/Retired/Archived states.
   - Device IDs are not regenerated during assignment/transfer.

7. REPLACEMENT SAFETY
   - Old Device ID becomes REPLACED and disabled.
   - New Device ID is generated cleanly without inheriting terminal lifecycle flags.

8. PROFILE LIFECYCLE BACKEND ENFORCEMENT
   - resolveNfcDevice rejects suspended/archived/cancelled profiles.
   - recordNfcTap also respects profile lifecycle.
   - Archived profiles use legacy suspended state so the existing public card path is also unavailable while archived.

9. ACTIVATION SAFETY
   - activateNfcBatch preserves terminal device states instead of reactivating Lost/Stolen/Replaced/Retired/Archived devices.
   - nfcDevicePublic is synchronized during activation.

10. AUDIT EVENTS
   - Profile Created
   - Profile Suspended / Reactivated / Archived
   - Device Suspended / Reactivated / Lost / Stolen / Retired / Archived / Replaced
   - Batch Assigned / Transferred / Disabled / Reactivated
   - Client NFC Type Control Changed

IMPORTANT SECURITY NOTE
NTAG215/216 chips are not cryptographic anti-cloning chips. Device-ID provides official registration, control, analytics, suspension and replacement, but a readable resolver URL can still be copied to another basic NFC chip. True cryptographic anti-cloning requires secure hardware such as NTAG 424 DNA/SUN or equivalent.
