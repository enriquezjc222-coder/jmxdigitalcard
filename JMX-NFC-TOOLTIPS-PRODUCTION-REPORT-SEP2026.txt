PRODUCTION NFC LIFECYCLE BACKEND
Two authenticated administrator-only callable functions were added:
- returnNfcCardToInventory
- deleteNfcClientCard

returnNfcCardToInventory:
- restricted to official NFC-ID clients;
- requires an exact linked one-card activation batch;
- removes owner/profile/admin association documents for that NFC-ID client;
- rotates the activation code to a new cryptographically generated code;
- returns the physical NFC card/batch to Available;
- keeps an administrative NFC event entry.

deleteNfcClientCard:
- restricted to official NFC-ID clients;
- requires an exact linked one-card activation batch;
- permanently removes the exact client/card/device/batch association documents;
- keeps an administrative deletion event entry.
