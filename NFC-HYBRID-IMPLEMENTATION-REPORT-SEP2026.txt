DEPLOYMENT REQUIRED
The new system is not only static frontend code. To make Device IDs work online, deploy:
1. Firebase Hosting (firebase.json includes /d/** rewrite).
2. Firestore Rules.
3. Cloud Functions (resolveNfcDevice, recordNfcTap, activateNfcBatch and NFC settings helpers).
4. Existing Firebase project must remain the same jmx-digital-card project.

GitHub Pages alone cannot execute the Firebase Cloud Functions. If GitHub Pages remains the public custom-domain host instead of Firebase Hosting, /d/DEVICE-ID clean-path routing will need an equivalent GitHub-compatible route/fallback strategy; device.html?device=DEVICE-ID can still be used. The current Firebase configuration already declares Hosting, so Firebase Hosting is the recommended route for the clean /d/DEVICE-ID resolver.
